# Projetos de Sites

Sites e protótipos que estamos desenvolvendo para vender.

## Estrutura

```
sites/
  amazon-berry/          Site da Amazon Berry (açaí) – versão de apresentação v2
    index.html
    images/              Fotos em WebP + logo
    fonts/               Fontes hospedadas no próprio site (licença OFL)
    LEIA-ME.txt          Notas da versão e pendências com o cliente

prototipos/
  cardapio-em-livro/     Cardápio com efeito de livro
  monte-seu-bolo/        Montador interativo de bolo
  prototipo-do-fio/      Protótipo com fio desenhado ao rolar a página
```

## Como abrir

Cada pasta tem um `index.html`. Basta dar dois cliques para abrir no navegador.

Para mostrar a um cliente, suba a pasta do projeto (com `images` e `fonts`, se houver)
no Netlify, Vercel ou GitHub Pages e envie o link.
